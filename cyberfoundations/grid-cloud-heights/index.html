The Grid & Cloud Heights

Follow the connection. Prove what works.

Move from network fundamentals into cloud access, troubleshooting, and least-privilege network security.

Week 5 ↓Week 6 ↓Week 7 ↓
Week 05PROJECT OVERVIEW

Investigate The Grid.

Identify addresses and network settings, diagnose an outage, and read a recorded packet capture. Use a structured troubleshooting sequence to distinguish naming problems from reachability failures and explain what the traffic shows.

What goes into the portfolio

Networking worksheets, an incident explanation, and selected packet evidence.

IP addressing · DNS · DHCP · Packets

Week 06PROJECT OVERVIEW

From The Grid to Cloud Heights.

Carry your networking skills into a cloud environment. Connect to your assigned virtual machine, inspect its environment, and investigate connectivity through guided cloud troubleshooting.

What goes into the portfolio

Cloud-access and investigation documentation explaining observations and diagnostic results.

Cloud infrastructure · Remote access · Troubleshooting

Week 07PROJECT OVERVIEW

Defend the Guard Post.

Read network security rules, design a narrowly scoped service allow, and test both allowed and denied outcomes. Diagnose a controlled rule-priority fault and document why the final configuration works.

What goes into the portfolio

A network security investigation with test evidence and Deliverable 2.

Network rules · Least privilege · Verification
